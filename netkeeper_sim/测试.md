# NetKeeper Sim 项目总结

## 项目概述

**NetKeeper Sim** 是一个基于**多智能体强化学习（Multi-Agent RL）**的**网络模拟内核**，旨在复现 **NetKeeper** 论文的核心概念。该项目通过 COMA（Counterfactual Multi-Agent Policy Gradients）算法与共享的 Graph Transformer 编码器，自动优化网络中的 OSPF 链路权重、BGP 路由属性以及链路性能参数，并根据高层运维策略（Operator Policy）来指导优化方向。

---

## 项目架构

项目分为两大子系统：

### 1. 确定性模拟内核（Deterministic Simulation Kernel）

基础的网络模拟栈，支持加载真实拓扑、路由计算、流量传播和指标评估。

| 模块 | 路径 | 功能 |
|---|---|---|
| **Topology（拓扑）** | `topology/` | 加载 Internet Topology Zoo 的 `.graphml` / `.gml` 文件，标准化节点和链路属性 |
| **Routing（路由）** | `routing/` | OSPF 最短路径计算（保留所有 ECMP 等价下一跳）、简化 BGP 最优路径选择 |
| **Traffic（流量）** | `traffic/` | 流量矩阵管理（CSV/NumPy/随机生成）、基于 ECMP 的逐跳流量传播 |
| **Metrics（指标）** | `metrics/` | 链路利用率、最大链路利用率、转发平面流量偏移（Traffic Shift）计算 |
| **Policies（策略）** | `policies/` | 三种运维策略：ForwardPolicy、ReachablePolicy、IsolationPolicy |
| **Simulator（模拟器）** | `simulator/` | `NetworkSimulationEnvironment` 统一门面，整合所有模块对外暴露 API |
| **CLI** | `cli.py` | 命令行入口，支持加载拓扑、注入流量、打印统计信息 |

### 2. 多智能体强化学习适配层（Multi-Agent RL Adapter）

将确定性模拟内核包装为三智能体 RL 环境，使用 GNN + COMA 进行训练。

| 模块 | 路径 | 功能 |
|---|---|---|
| **环境层** | `rl/multi_agent_env.py` | `MultiAgentNetworkEnvironment`：reset/step 接口，应用 7 类参数动作，计算奖励 |
| **图状态** | `rl/graph_state.py` | `NetworkGraphState`：17 维节点特征 + 11 维边特征 + 动作掩码 |
| **动作空间** | `rl/action_space.py` | 因子化的 7 掩码动作空间（OSPF 权重、BGP LocalPref/AS Path/MED、带宽/容量/队列） |
| **观测** | `rl/observations.py` | 三个局部观测：OSPF 看策略+利用率，BGP 看策略，Performance 看利用率 |
| **奖励** | `rl/rewards.py` | 策略满足度奖励 + 资源利用率奖励 + 静态/动态辅助奖励 |
| **图编码器** | `rl/networks/graph_encoder.py` | 共享 Graph Transformer（GINEConv + TransformerConv + 全局池化） |
| **Actor** | `rl/networks/multi_agent_actor.py` | 三个独立 Actor Head（OSPF/BGP/Performance），共享编码器 |
| **Critic** | `rl/networks/centralized_critic.py` | 集中式 Critic，独立编码器 |
| **训练器** | `rl/trainer.py` | COMA 训练循环：ε-greedy 探索、mini-batch、梯度裁剪、目标网络更新 |

## 核心工作流程

```
┌──────────────────────────────────────────────────────────────┐
│  1. 加载拓扑 (Internet Topology Zoo .graphml / .gml)          │
│     ↓                                                         │
│  2. 标准化节点/链路属性 → 填充模拟默认值                        │
│     ↓                                                         │
│  3. OSPF 最短路径计算（保留所有 ECMP 等价下一跳）                │
│     ↓                                                         │
│  4. BGP 最优路径选择（LocalPref > AS Path > MED > IGP > Tie）  │
│     ↓                                                         │
│  5. 流量矩阵注入 → ECMP 逐跳分流传播 → 链路负载累加             │
│     ↓                                                         │
│  6. 指标评估：策略满足度 / 链路利用率 / 流量偏移                 │
│     ↓                                                         │
│  ─────────── RL 层循环 ───────────                             │
│     ↓                                                         │
│  7. 图状态编码 (17-dim node + 11-dim edge features)            │
│     ↓                                                         │
│  8. Graph Transformer 编码 → 全局图嵌入                         │
│     ↓                                                         │
│  9. 三智能体各自输出因子化动作（7 类参数，每类 1-128 离散值）    │
│     ↓                                                         │
│  10. 应用动作 → 重新计算路由/流量/指标 → 计算奖励               │
│     ↓                                                         │
│  11. COMA 更新（集中式 Critic + 反事实基线 + TD 学习）          │
│     ↓                                                         │
│  循环至策略满足度达到 1.0 或达到最大步数                         │
└──────────────────────────────────────────────────────────────┘
```

---

## 三个 RL 智能体

| 智能体 | 可调参数 | 观测空间 | 奖励信号 |
|---|---|---|---|
| **OSPF Agent** | 每条链路的 OSPF 权重 [1,64] | 策略满足向量 + 链路利用率 | R_pol + R_res |
| **BGP Agent** | 每条路由的 LocalPref / AS Path Length / MED [1,64] | 策略满足向量 | R_pol |
| **Performance Agent** | 每条链路的带宽 / 容量 / 队列长度 [65,128] | 链路利用率 | R_res |

## 测试覆盖

共 25 个测试文件，覆盖两大子系统：

- **确定性模拟**：拓扑加载、OSPF、ECMP、BGP、流量矩阵、流量传播、链路故障、策略一致性、流量偏移、评估指标
- **RL 适配层**：图状态编码、动作空间、奖励计算、多智能体环境、图编码器、Actor Head、集中式 Critic、COMA 基线/损失、回放缓冲、训练冒烟测试

## 设计特点

1. **真实拓扑驱动**：基于 Internet Topology Zoo 的 276 个真实 ISP 拓扑
2. **ECMP 完整支持**：保留所有等价下一跳，而非仅单条最短路径
3. **并行链路处理**：MultiGraph 支持，路由时按最小权重折叠，负载均衡时等分流量
4. **PyTorch 可选**：确定性内核无需 PyTorch，`_tensor.py` 抽象层自动选择 torch.Tensor 或 np.ndarray
5. **BGP + OSPF 集成**：BGP 选择出口下一跳，OSPF/ECMP 将流量转发至该出口
6. **因子化动作空间**：3 个智能体 × 7 类参数的离散动作空间，每类最多 128 种取值
7. **COMA 多智能体训练**：反事实基线、集中式 Critic、ε-greedy 探索、TD 学习
